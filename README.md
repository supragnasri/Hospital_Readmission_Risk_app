# Hospital_Readmission_Risk_app
Patient Readmission Risk Prediction System uses machine learning models built with scikit-learn to predict hospital readmission risk based on patient data. The trained model is deployed through an interactive web app using Streamlit for real-time predictions.
Technologies Used

Python
scikit-learn
Streamlit
Pandas
NumPy


Dataset Features

The model uses patient information such as:
Age
Gender
Region
Primary diagnosis
Comorbidities count
Length of hospital stay
Treatment type
Medications count
Previous readmissions

Insurance type

Discharge disposition
